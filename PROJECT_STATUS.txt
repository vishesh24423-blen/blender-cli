Architecture:
------------
1. User submits script via Next.js frontend
2. API creates job in Firestore (status: queued)
3. API checks runner status via transaction
4. If runner inactive/stale, trigger GitHub Actions
5. GitHub Actions installs Blender and runs worker
6. Worker polls Firestore for queued jobs
7. Worker executes script in Blender
8. Worker exports to requested formats
9. Worker uploads files to R2
10. Worker updates job status to 'done'
11. User downloads files from R2
